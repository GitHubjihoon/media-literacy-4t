# 보이는 게 전부일까? — 웹 슬라이드 v2

위툰스쿨 미디어 리터러시 미니수업 PDF 42장을 웹에서 보는 슬라이드 뷰어입니다.
원본 페이지 순서와 디자인을 유지했으며, 별도 설치나 빌드 없이 GitHub Pages에 게시할 수 있습니다.

## 이번 수정

- 새로 제공한 `(청도 AI 캠프)[위툰스쿨]미디어 리터러시 미니수업_보이는 게 전부일까(교안).pdf`로 42장 전체를 다시 변환했습니다.
- 상단 제목과 하단 리모컨을 위한 고정 여백을 없애고, 원본 비율을 유지하면서 화면에 들어가는 최대 크기로 슬라이드를 표시합니다.
- 검정 배경을 밝은 색으로 바꾸고, 리모컨은 높이 약 46픽셀의 작은 형태로 화면 위에 띄웠습니다. 리모컨을 펼쳐도 콘텐츠 크기는 변하지 않습니다.
- 페이지 이동 방향에 맞춘 약 0.44초의 슬라이드·페이드 전환을 넣었습니다. 새 이미지가 준비된 뒤 전환하므로 로딩 중에는 이전 페이지를 유지합니다.
- 운영체제에서 동작 줄이기를 설정한 경우에는 전환 애니메이션을 생략합니다.
- 모바일 세로 화면에서는 가로 슬라이드 비율 때문에 여백이 생깁니다. 가로 방향으로 돌리면 콘텐츠가 더 커집니다.

## 먼저 열어보기

1. ZIP 파일의 압축을 풉니다.
2. `index.html`을 Chrome, Edge 등 최신 브라우저에서 엽니다.
3. `assets` 폴더와 나머지 파일은 함께 보관합니다. `index.html`만 옮기면 슬라이드가 표시되지 않습니다.

## 조작 방법

| 조작 | 동작 |
| --- | --- |
| 리모컨의 왼쪽 / 오른쪽 화살표 | 이전 / 다음 페이지 |
| 슬라이드 왼쪽 25% 클릭 | 이전 페이지 |
| 슬라이드 나머지 영역 클릭 | 다음 페이지 |
| 키보드 →, ↓, Space, PageDown | 다음 페이지 |
| 키보드 ←, ↑, Shift+Space, PageUp | 이전 페이지 |
| Home / End | 첫 페이지 / 마지막 페이지 |
| 리모컨 번호 입력 후 이동 또는 Enter | 원하는 페이지로 이동 |
| 네모 네 개 아이콘 또는 G | 전체 42장 목록에서 선택 |
| 전체 화면 아이콘 또는 F | 전체 화면 시작 / 종료 |
| 물음표 아이콘 또는 ? | 사용 방법 |
| 리모컨 왼쪽 점 손잡이 드래그 | 리모컨 위치 이동 |
| 손잡이 더블클릭 | 리모컨 기본 위치로 복귀 |
| 리모컨 오른쪽 ··· 버튼 | 전체 화면·목록·링크 복사 등 추가 도구 열기 |
| 추가 도구의 숨기기 또는 R | 리모컨 숨기기 / 표시 |
| 오른쪽 아래 작은 페이지 표시 | 숨겨진 리모컨 다시 표시 |
| 모바일에서 왼쪽 / 오른쪽으로 쓸기 | 다음 / 이전 페이지 |

페이지 번호 입력 중에는 방향키와 Space가 슬라이드 이동을 일으키지 않습니다.
첫 장과 마지막 장에서는 범위를 벗어나지 않습니다.
전체 화면 기능은 지원하는 브라우저에서 사용할 수 있습니다.
약 3초 동안 조작이 없으면 리모컨이 작은 페이지 표시로 접힙니다. 리모컨 위에 마우스가 있거나 번호 입력·키보드 조작 중이면 접히지 않습니다.

## GitHub Pages에 올리기

1. GitHub에서 이 수업을 담을 저장소를 준비합니다. 무료 계정이라면 공개(Public) 저장소를 사용합니다.
2. 압축을 푼 **폴더 안의 파일과 `assets` 폴더**를 저장소 최상위에 업로드합니다.
   ZIP 자체를 올리거나, 상위 폴더 안에 `index.html`을 넣지 않도록 합니다.
3. 업로드 후 저장소 최상위에 다음 구조가 있는지 확인합니다.

   ```text
   index.html
   style.css
   app.js
   slides.js
   .nojekyll
   README.md
   assets/
     favicon.svg
     slides-v2/
       slide-01.webp
       ...
       slide-42.webp
     thumbs-v2/
       slide-01.webp
       ...
       slide-42.webp
   ```

4. 저장소 **Settings → Pages**로 이동합니다.
5. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
6. 파일을 올린 브랜치(보통 `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
7. 배포가 완료되면 Pages 설정에 표시된 사이트 주소를 열어 공유합니다.

공식 안내: [GitHub Pages 게시 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

이전 버전을 이미 게시했다면 이 ZIP의 전체 내용을 같은 저장소에 덮어씁니다. 새 `assets/slides-v2`와 `assets/thumbs-v2` 폴더도 함께 올려야 합니다. 예전 `assets/slides` 폴더는 v2에서 사용하지 않습니다.

## 특정 페이지 공유

게시된 사이트에서 원하는 슬라이드로 이동한 뒤 리모컨 **··· → 링크 복사 아이콘**을 누릅니다.
주소 끝의 `#page=12`처럼 페이지 번호가 함께 저장되어, 받는 사람이 그 페이지부터 볼 수 있습니다.
로컬 파일 또는 localhost 미리보기 주소는 다른 사람에게 공유할 수 없으므로, 이 상태에서는 게시 안내를 표시합니다.

## 구성

- 42장의 슬라이드를 가로 2,560픽셀 WebP로 변환했습니다. 본문 이미지 합계는 약 7.3MB입니다.
- 목록에는 가로 480픽셀의 별도 미리보기 이미지를 사용합니다.
- 슬라이드의 내부 내용은 원본 PDF의 고정된 페이지이며, 페이지 간 전환에만 애니메이션을 적용합니다.
- 원본 PDF에 포함된 QR 코드는 슬라이드 이미지 안에 그대로 유지했습니다.
- 첫 방문에는 현재 슬라이드와 인접 슬라이드를 읽습니다. 전체 목록은 처음 열 때 생성합니다.
- 외부 라이브러리, 외부 폰트, 별도 서버, 로그인, API 키가 필요하지 않습니다.
- 원본에서 추출한 텍스트를 각 슬라이드의 대체 텍스트로 제공합니다. 이미지 위주인 표지와 마지막 장에는 페이지 설명을 넣었습니다.
- 원본 PDF는 배포 폴더에 중복 포함하지 않았습니다. 이 폴더만으로 작동합니다.

## 확인한 동작

실제 브라우저에서 다음 항목을 확인했습니다.

- 이전·다음 버튼, 화면 클릭, 방향키, Space, Home/End
- 페이지 직접 입력과 범위 밖 입력 차단
- 42장 목록과 선택한 페이지로 이동
- 리모컨 드래그, 위치 초기화, 접기·펼치기
- 전체 화면 시작·종료
- 전환 중 연속 방향키 입력과 최종 페이지 일치
- 리모컨 자동 숨김·복원
- 페이지 번호를 포함한 주소와 새로고침 시 페이지 유지
- 데스크톱(1440×900), 모바일 세로(390×844), 모바일 가로(844×390) 화면 배치

GitHub 업로드 및 공개 배포는 이 파일 묶음 제작에 포함되지 않았습니다.
